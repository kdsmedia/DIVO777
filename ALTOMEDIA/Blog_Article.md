## The technical story behind the build

For readers who are interested in how a modern Android app is put together, here
is a quick look under the hood of DIVO777.

The app is written in **Kotlin**, the language that has been the preferred
language for Android development since 2019. The user interface is built with
**Jetpack Compose**, Android's modern declarative UI toolkit. With Compose, the
entire screen is described as a function of the current state — when the state
changes, the UI updates automatically. This makes the reel animations, the pay
line highlighting, and the credit balance updates all flow naturally from a
single source of truth.

The build system is **Gradle** with the **Android Gradle Plugin**, configured
using the Kotlin DSL. A central version catalog keeps every dependency version
in one place, which makes the project easy to maintain and update. The release
artifact is an **Android App Bundle**, the modern distribution format that
allows Google Play to deliver an optimised APK to each device configuration,
keeping the download size as small as possible.

The game's artwork — the symbols, the background, the logo, the pay table, and
the pay lines panels — is rendered from crisp, optimised PNG assets that are
sized for a wide range of screen densities. The fonts include a bold display
face for headings and a readable serif for body text, giving the app a
distinctive look that fits the classic casino theme.

The app is signed with a dedicated release keystore, which means every update
published to the Play Store is verified as coming from ALTOMEDIA. The signing
configuration is kept separate from the source code, so the keystore never
enters version control, and the app is built and signed in a single reproducible
step.
